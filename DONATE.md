## Where the money goes · 用途

Fanctl has no running costs beyond the developer's time. Tips go toward:

- an Apple Developer account ($99/year) so releases can be signed and notarized —
  this removes the "unidentified developer" warning for every user
  （Apple 开发者账号，用于签名与公证，可去掉所有用户首次打开时的安全拦截）
- test hardware for other chassis (M1/M2/M3, 16-inch, Mac mini) to validate the
  thermal model beyond the developer's own machine
  （其他机型的测试设备，用于验证热模型）

No donation is ever required to use any feature. 所有功能永久免费，捐赠完全自愿。
